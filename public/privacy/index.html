About this policy

Git Client Preview is an independent macOS application developed by Shawn Moore. This policy describes the current preview and its informational website. Features can change during development; this page will be updated when relevant data handling changes.

The app works with Git repositories on your Mac. Signing in to a hosting provider, using remotes, and other connected features involve communication with those services.

Data stored on your Mac

The app reads repository files, Git history, commit authorship, branches, and related metadata to provide its features. App data stored locally can include:

  • Repository locations, library entries, settings, and window state.
  • Commit drafts, cached hosting information, and account metadata such as usernames, service addresses, and granted access scopes.
  • Operation history, diagnostic information, snapshots, and recovery content, which may include repository content.

App-managed account tokens and refresh tokens are stored in macOS Keychain. These credentials are configured not to sync through iCloud Keychain. Other Git credential helpers or SSH agents that you configure have their own storage behavior.

The app does not provide iCloud synchronization of its settings. Local app data and repositories may still be included in backups or synchronization tools you configure separately.

When the app connects to services

Sign-in, repository browsing, pull requests, notifications, and other hosting features communicate with the Git hosting services you configure. Git fetch, pull, push, and clone operations communicate with repository remotes. Depending on your settings, refreshes or fetches may happen in the background, and author images may be fetched from hosting services.

Data sent can include authorization credentials, API requests, repository identifiers, and the content needed for the action, such as commits, files, or review comments. Each provider handles this information under its own policies.

GitHub authorization can include access to public or private repositories, notifications, and organization information, depending on the permissions requested and granted. Private-repository access is not limited to read-only access. Review GitHub’s authorization screen before approving access.

See the GitHub Privacy Statement for GitHub’s handling of information. If you configure other providers, external tools, or custom commands, their policies and behavior apply as well.

Apple Intelligence features are not enabled in the version 0.1 preview covered by this policy.

Analytics and diagnostics

The current app does not collect usage analytics or automatically send crash reports to the developer. The app’s Journal can save diagnostic reports locally. You decide whether to share a report. Review it first: repository paths, command output, names, or other private information may be present.

macOS diagnostics and any sharing you enable in operating-system settings are managed by Apple, separately from the app.

Visiting this website

This is a static website hosted by GitHub Pages. It does not add analytics, advertising trackers, cookies, contact forms, or third-party fonts. Images and styles are served with the site.

GitHub processes requests to serve the website. GitHub states that Pages visitors’ IP addresses are logged and stored for security purposes, whether or not a visitor is signed in to GitHub. GitHub’s privacy policy governs its hosting data.

Following a link to GitHub or another website takes you to a service with its own privacy practices.

Support through GitHub Issues

Support is handled in the public website issue tracker. When you submit an issue or comment, your GitHub username, the text you post, and any attachments are available publicly. GitHub processes those interactions under its own policies.

The developer uses information you submit to respond to questions, investigate problems, and improve the app. Public posts may remain visible in GitHub history or copies made by others.

Do not post secrets, private repository content, personal data, or unredacted logs. For a sensitive request, ask for a private contact method without describing the sensitive details in the public issue.

Your controls

  • Disconnect an account: sign out in Accounts to remove the app’s stored credentials for that account. Removing an account also removes its account record.
  • Revoke GitHub access: use GitHub’s application settings. Signing out locally does not itself revoke authorization at GitHub.
  • Manage repositories: removing a repository from the app’s library does not delete the repository’s files from your Mac.
  • Control sharing: inspect and redact diagnostic reports before attaching them to an issue.

Signing out or uninstalling the app does not necessarily remove local databases, caches, recovery archives, repositories, or backups. If you need help locating app data, use the support page without posting your private file paths.

Changes and privacy questions

Changes to this policy will be published here with an updated date. For questions about the app’s data handling, open a privacy question on GitHub. A dedicated support or privacy email is not currently provided.

Ask a question ↗

A GitHub account is required to create an issue. This is a preview maintained by an independent developer; response times may vary.

Help make the issue reproducible.

  • Your Git Client Preview version or build, and your macOS version.
  • The steps that led to the problem.
  • What you expected to happen, and what actually happened.
  • A screenshot or a small example, if useful, with private details removed.

If you have a preview build, Help → GitClient Help explains the app’s workflows. For a failing operation, the Journal may contain useful details. Export Diagnostics… saves a report locally for you to inspect before sharing.

GitHub issues are public.

Never post access tokens, passwords, SSH private keys, private repository contents, or unredacted diagnostic reports. Remove private file paths, email addresses, and other identifying details from screenshots and logs.

For a security concern or a sensitive privacy request, open an issue asking for a private contact method and omit the sensitive details. A dedicated support email is not currently provided.

Read the privacy policy for how the app, this website, and support interactions handle information.

A few common questions.

Where can I download the app?

A public download is not available on this website yet. The app is in development, and this site provides product information, support, and privacy details.

Which Macs does the preview target?

The current preview targets macOS 27 or later on a Mac with Apple silicon.

Why might GitHub sign-in be unavailable?

Browser sign-in depends on the app’s GitHub registration being configured in your build. If sign-in is unavailable or fails, include your build version and the visible error in an issue. Do not include access tokens or sign-in codes.

How do I disconnect a GitHub account?

Sign out in the app’s Accounts settings to remove its locally stored account credentials. To revoke the app’s GitHub authorization too, visit GitHub’s application settings. Signing out does not delete your repositories or all cached app data.
